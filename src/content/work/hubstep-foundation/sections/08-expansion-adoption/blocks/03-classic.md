### Classic mode

*Migrating to a new foundation without breaking the existing flow*

Classic mode was defined by the PdM and stakeholders as the path for migrating existing users from the legacy DMBOX system to hubstep.

My role was to **redesign the UI on hubstep without significantly changing the operational flow and information structure existing users were already used to.**

While following the existing way of working, I also improved usability and addressed new system requirements.
